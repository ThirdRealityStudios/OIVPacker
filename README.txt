The OIV Tools are a bundle of tools in order to simplify the modification of GTA IV.
There aren't that many tools on the internet that really make modding as easy as with OIV Tools.
OIV Tools can help you to create .oiv modpacks to install them with OpenIV (not related / affiliated to OIV Tools).
Summarized, if you want to get the OIV Tools, then you will receive two tools in a single .zip file:

* OIV Unpacker
* OIV Packer

How To Use:

1. Open start menu or press Windows key
2. Search for "cmd.exe" or "powershell.exe"
3. Open one of them
4. Type in the command "cd <directory path of your extracted files>"
5. Type in the command ".\packer.exe" or simply "packer.exe"
6. Follow the instructions on the console (especially parameters)

Program Does Not Work As Expected

- run your console as administrator (right-click on "cmd.exe" in start menu -> Run as administrator) and try again
- make sure you have a stable internet connection

Product Key:

Both, OIV Unpacker and OIV Packer,
require a product key in order to use them.
The two product keys are contained in a text document (distributed in .zip file).

Key Validity:

* always valid for 1 year (and a little more for possible unexpected issues) since you have received the .zip file.
* if expired please and simply come back into this channel to get a new licensed software (again as a .zip file with a new product key).

Product Requirements:

* Windows 11 64 Bit (tested)
* a stable internet connection (always required when starting to verify your license and for activation)
