The OIV Tools are a bundle of tools in order to simplify the modification of GTA IV.
There aren't that many tools on the internet that really make modding as easy as with OIV Tools.
OIV Tools can help you to create .oiv modpacks to install them with OpenIV for GTA IV (not related / affiliated to OIV Tools).

* OIV Unpacker
* OIV Packer (which this README is about now in the following)

OIV Packer
----------

How To Use:

1. Extract all files into any empty folder
2. Never delete the file "icon.png"
3. Open start menu or press Windows key
4. Search for "cmd.exe" or "powershell.exe"
5. Open one of them two
6. Type in the command "cd <directory path of your extracted files>" and hit enter
7. Type in the command ".\packer.exe" or simply "packer.exe" and hit enter
8. Consult the section "Product Key / Activation" in README.txt
9. Follow the instructions on the console (especially parameters)

Create Your Own Modpack Preview Picture:

1. Open the extracted file "icon.png", e.g. with Gimp or Paint
2. The icon image size always (!) must be 128x128 pixels
3. Otherwise paint and edit the image as you want

Program Does Not Work As Expected:

- Run your console as administrator (right-click on "cmd.exe" in start menu -> Run as administrator) and try again
- Make sure you have a stable internet connection

Product Key / Activation:

OIV Packer requires a product key in order to use it.
The product key is contained in file "Product_key.txt" (also in your received .zip archive).
You will be prompted from the console for the key after starting the program.

Key Validity:

* Always valid for 1 year since you have received the program.
* If expired you can come back to the Discord server to discuss a simple renewal (again as a .zip file with a new product key).

Product Requirements:

* Windows 11 64 Bit (tested)
* A stable internet connection (always required when starting to verify your license and for activation)
* Windows installed on drive letter C:
