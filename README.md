# OIV Unpacker for OpenIV

This program unpacks every .oiv installation archive.
It will help you to restore the files and directories before
they were encoded in a .oiv archive.

## What is an .oiv archive?

An .oiv archive is always an automatic installation archive
for mods in GTA.
Simply speaking,
they are just modpacks which you can install with OpenIV.

## What is OpenIV?

OpenIV on the other hand is a tool which can modify GTA IV archive formats
(which you can obviously not open with default tools, e.g. 7zip or WinRar).
Anyway,
OpenIV can also execute modpacks (automatic installation programs for mods),
the .oiv archives.

## What game versions does OIV Unpacker support?

Currently,
only GTA IV is supported.

## Example

You want to download some new road textures for GTA IV.
The mod you download is provided as an .oiv archive,
e.g. named "roadTextures.oiv".
Now you can use this program here on GitHub in order
to decode the .oiv archive.
It will extract all files and will place them in folders
which will remember you of the directory structure of your GTA IV game.

## Sense of this program

The sense of this program is,
you can create much easier modpacks for GTA.

### Reasons

#### 1

You know exactly where files will be placed later in your GTA IV directory.

#### 2 (very important)

You will know exactly if multiple mods downloaded will overwrite each others files
(which is why they are not compatible with each other e.g. and will crash the game most likely).

### Note

As you read,
you only need the OIV Unpacker if you want to include a .oiv mod
in your current modpack project.
Otherwise,
you will only need the OIV Packer (read below).

## But how to create a modpack?

The modpack can be created on the other hand with my tool called "OIV Packer".
You simply specify the location of your modpack directory which contains
the GTA IV directory structure.
Automatically,
it will create a .oiv installation archive for you.
After that,
you open the program OpenIV and simply click on install.
